- 戦闘全体の与ダメージ合計

- ゲーム内Ajax履歴の記録と、現在地・ターン・通貨・収縮状態候補の自動抽出

貢献度は名前と別行で表示し、1万以上は `12.5万`、1億以上は `1.2億` のように短縮します。完全な数値はツールチップで確認できます。
キャラクター別の数値も同じ形式で短縮し、完全な数値はツールチップに表示します。

戦闘タブはターン内の見出しと数値を横並びにし、カード間隔・余白・行間を圧縮しています。キャラクター別表示は現在のフロントメンバーだけを対象とし、`formation` の順序で表示します。キャラクター一覧全体を独立した「現在ターン」と「前ターン」の2テーブルに分けて横並びにし、各キャラクターの `hit・アビ・奥義` を同じ行順で配置します。キャラクター名は現在ターン側だけに表示します。各テーブルのhit列は3桁幅、アビ・奥義列へ残りの幅を配分します。貢献度順位は角括弧表記ではなく、1～3位を色分けした順位バッジと名前・貢献度の分離表示を使用します。

同一戦闘の状態は永続ストレージにも保存します。ページをリロードして同じ `raid_id` の `start.json` を受信した場合は、累計・ターン・キャラクター・参戦者情報を復元し、別の `raid_id` が始まった場合だけリセットします。
復元したキャラクター別前ターン配列にインデックスがない場合も、配列位置を補完して対応するフロント行へ表示します。

## インストール・更新

1. Chromeで `chrome://extensions/` を開く。
2. デベロッパーモードを有効にする。
3. 「パッケージ化されていない拡張機能を読み込む」で `D:\Dropbox\scripts\#GBFtools\testExtension` を指定する。
4. 更新後は拡張機能の再読み込みボタンを押す。
5. GBFタブも再読み込みする。
6. 拡張機能アイコンを押してサイドパネルを開く。
